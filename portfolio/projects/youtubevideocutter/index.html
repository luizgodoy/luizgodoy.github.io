YouTubeVideoCutter

Aplicativo local em Blazor Server e FFmpeg para download, corte e edição de mídia do YouTube.

Categoria: Mídia & Torneios Status: Ativo Repositório Privado Atualizado em: 2026-09-25

Visão Geral & Objetivos

Ferramenta desenvolvida para execução local que permite o download e recorte de trechos específicos de áudio e vídeo do YouTube em alta velocidade utilizando o FFmpeg em modo cópia direta sem re-codificação.

Principais Funcionalidades Identificadas

  • Download sob demanda e sistema de cache local de mídia para economia de banda
  • Corte ultra-rápido de segmentos de vídeo sem perda de qualidade (stream copy via FFmpeg)
  • Interface interativa em Blazor Server para seleção visual de timestamps de início e fim
  • Exportação de faixas de áudio isoladas (MP3/M4A) ou vídeos completos (MP4)

Tecnologia & Arquitetura

Aplicação web local em Blazor Server acoplada ao executável do FFmpeg gerenciado através de processos seguros em segundo plano.

Tecnologias Utilizadas:
.NET 8C#ASP.NET Core Blazor ServerFFmpegLocal Cache System
