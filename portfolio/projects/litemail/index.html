LiteMail — Webmail Multi-Domínio

Cliente webmail corporativo multi-domínio em ASP.NET Core e MailKit.

Categoria: Dados & Produtividade Status: Ativo Repositório Privado Atualizado em: 2026-09-25

Visão Geral & Objetivos

Interface web moderna e leve para leitura, envio e gerenciamento de caixas de correio eletrônico em múltiplos domínios, com suporte a servidores SMTP/IMAP corporativos (Mailcow/Docker).

Principais Funcionalidades Identificadas

  • Acesso a caixas postais IMAP com renderização segura de e-mails em HTML
  • Composição e envio de mensagens com anexos via protocolo SMTP com TLS/SSL
  • Suporte nativo a múltiplos domínios de correio em um único portal
  • Isolamento de sessão de usuário e credenciais temporárias em memória

Tecnologia & Arquitetura

Camada de interface webmail desacoplada do servidor de correio (Mailcow), utilizando a biblioteca MailKit para orquestração de protocolos.

Tecnologias Utilizadas:
C#ASP.NET Core 8 MVCMailKitMimeKitDockerMailcow
