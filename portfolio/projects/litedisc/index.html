LiteDisc

Plataforma de armazenamento em nuvem e gerenciamento seguro de arquivos multi-backend.

Categoria: Dados & Produtividade Status: Ativo Repositório Privado Atualizado em: 2026-09-25

Visão Geral & Objetivos

Serviço web construído em ASP.NET Core 8 MVC para upload, download, pré-visualização e organização de pastas de arquivos isolados rigorosamente por usuário.

Principais Funcionalidades Identificadas

  • Gerenciador de arquivos completo com navegação hierárquica e breadcrumbs
  • Suporte a uploads de grandes arquivos (até 500 MB) em lote
  • Controle de acesso rigoroso por conta com isolamento físico de diretórios
  • Busca rápida por nome de arquivo e extensão

Tecnologia & Arquitetura

Arquitetura ASP.NET Core MVC com abstração de provedor de armazenamento (Local Disk / Cloud Storage) e metadados no SQLite.

Tecnologias Utilizadas:
C#ASP.NET Core 8 MVCSQLiteEntity Framework Core
