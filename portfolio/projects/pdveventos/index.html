PdvEventos — Frente de Caixa para Eventos

Sistema de Frente de Caixa (POS) de alto desempenho com interface moderna para feiras e eventos.

Categoria: Gestão & Operações Comerciais Status: Ativo Repositório Privado Atualizado em: 2026-09-25

Visão Geral & Objetivos

Plataforma focada em velocidade de atendimento em balcões de eventos temporários, festas e feiras, combinando design moderno Glassmorphism com operação tolerante a instabilidade de rede.

Principais Funcionalidades Identificadas

  • Interface rápida e intuitiva no padrão Glassmorphism pensada para telas touch e operadores rápidos
  • Emissão e controle de fichas de produtos e consumações com QR code / código de barras
  • Fechamento de caixa por operador com conferência detalhada por forma de pagamento
  • Relatórios consolidados de vendas por hora e produtos mais comercializados

Tecnologia & Arquitetura

Aplicação web local de alta performance com banco embutido SQLite para garantir que o caixa opere sem interrupções mesmo sem internet.

Tecnologias Utilizadas:
C#ASP.NET CoreEntity Framework CoreSQLiteHTML5 / Modern CSS
