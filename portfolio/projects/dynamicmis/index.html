DynamicMIS — Informações Gerenciais Dinâmicas

Plataforma flexível de Business Intelligence e gestão de informações gerenciais em .NET 8.

Categoria: Dados & Produtividade Status: Ativo Repositório Privado Atualizado em: 2026-09-25

Visão Geral & Objetivos

Sistema corporativo multi-empresa que possibilita aos gestores cadastrar entidades e atributos de dados de forma dinâmica e em tempo de execução, eliminando a dependência de código novo para novas coleções de indicadores.

Principais Funcionalidades Identificadas

  • Estrutura multi-tenant com isolamento lógico estrito de dados por empresa
  • Definição de entidades e atributos customizados dinamicamente pelo painel
  • Dashboards com gráficos analíticos e métricas gerenciais em tempo real
  • Exportação de tabelas dinâmicas para análise externa

Tecnologia & Arquitetura

Padrão MVC com metamodelo relacional para propriedades dinâmicas e EF Core para gerenciamento de esquema.

Tecnologias Utilizadas:
.NET 8C#ASP.NET Core MVCEntity Framework CoreSQLite
