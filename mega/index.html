Como começar

  1. Clique em ＋ Novo projeto.
  2. Informe identificador, concurso e data-base e salve.
  3. Selecione de 6 a 20 dezenas-base.
  4. Gere um fechamento completo, uma amostra ou use o otimizador.
  5. Salve o projeto. Os dados ficam no navegador.

Persistência local

Esta versão usa JSON + localStorage. Cada projeto é armazenado pela chave Identificador|Concurso|Data-base.

O armazenamento é local ao navegador. Recomenda-se exportar o projeto JSON como backup.
